# For Your Next Chapter ❤️

A small personal website made as a digital surprise for a new beginning in Hyderabad.

## Files
- `index.html` — page structure and message
- `style.css` — responsive visual design
- `script.js` — opening animation

## Personalization
You can later add a photo, voice note, or a custom section to make it even more personal.

## Publish with GitHub Pages
Open **Settings → Pages** in this repository, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
